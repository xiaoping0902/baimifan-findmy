# 原生悬浮窗口与灵动岛修复

用户要求：iOS 风格、流畅拖动、整个屏幕范围移动、顶部正中灵动岛、面板可放大缩小，并上传 GitHub 编译。

采用现有 Objective-C++ / UIKit / Metal。面板仍由现有七页 ImGui 界面渲染；实际位置和尺寸归原生小窗口所有。灵动岛使用独立 UIKit 胶囊窗口，保持顶部居中，展开时也可点击收起。单个 HID 输入桥在两个有限窗口之间分配触点，保持稳定触点所有权与取消行为。

执行清单：

1. 校正坐标：全屏尺寸决定面板大小，局部 viewport 填满原生面板，标题栏拖动实际窗口。
2. 独立顶部岛及原生弹簧展开、收起、按压动画；保留 Reduce Motion 支持。
3. 右下角手柄和外观页滑杆同时改变实际窗口尺寸，旋转与屏幕边界正确约束。
4. 修复逐帧日志与设置同步写盘，滚动惯性与过渡期间保持活动刷新率。
5. 更新活跃菜单、岛触控及便携几何回归；在 Windows 跑可运行检查，在 GitHub macOS 验证 UIKit 与 iOS 构建。
6. 仅提交本任务文件，保留工作区原有改动，推送现有分支并核对 Actions / IPA 结果。

限制：本地 Windows 无 Apple SDK；几何或 CPU 单测通过不代表真机帧率和跨 App 触摸已验收。最终需要安装对应提交构建的 IPA 验证拖动、旋转、缩放与帧时。
