# 小玉 · 使用文档

> 面向使用者。装、开、用、出问题怎么办，全在这。

---

## 一、安装

1. iPad 用 **TrollStore**（或越狱端）安装 IPA。
2. 最新包地址（本机局域网，电脑必须开着服务）：

   ```
   http://192.168.2.4:8080/FindMy-ipa158.ipa
   ```

3. 装完桌面图标显示为「**查找**」（伪装名），点开就是小玉。

> **怎么确认装的是哪一版**：进 App 后看底部「构建信息」，会显示 `M5.1xx / <sha>-r<N>`。
> 版本不对就是包没覆盖成功，重装一次。

---

## 二、第一次使用（顺序别乱）

```
① 先开小玉（悬浮窗）        →  出现绿色悬浮按钮
② 再开三角洲                →  进训练营/对局
③ 悬浮按钮点一下 → 展开菜单
④ 主功能里勾「启用绘制」
```

> **为什么先开小玉**：内核读的句柄是小玉启动时申请的，先开游戏再开小玉通常也能用，
> 但如果出现「KFD 初始化失败」，就按上面顺序重来。

## 三、菜单说明

### 3.1 主功能

| 开关 | 作用 | 建议 |
|---|---|---|
| 总开关 | 全局启用 | 开 |
| 启用绘制 | 真正开始画 | 开 |
| **人机显示** | 是否画人机 | 开 |
| **队友** | 是否画同队队友 | **关**（默认不画） |
| 名字 | 头顶文字块 | 开 |
| 头甲 | `头X 甲Y 包Z` | 开 |
| 血量 | 左侧血条 | 开 |
| 距离 | 框下方 `[12m]` | 开 |
| **队伍** | `队N : UIN` | 开 |
| **射线** | 从屏幕顶部连到目标的细线 | 按喜好 |
| 手持 | `持 W802` | 开 |
| 骨骼 | 真骨架（19 关节） | 开 |

### 3.2 画面上你会看到什么

```
        持 W802          ← 手持武器（类型码）
      头6 甲6 包-        ← 头/甲/包等级（颜色随最高等级）
      队0 : 11102077440  ← 队伍号 : 玩家 ID
     敌人  100           ← 名字 + 当前血量
   ┌──────────────┐
   │              │      ← 方框 = 角色胶囊
   │   骨架 19 点  │      ← 红色骨架，贴合身体
   │              │
   └──────────────┘
        [12m]            ← 距离
```

**等级颜色**：2 绿 / 3 天蓝 / 4 紫 / 5 黄 / 6 红。

## 四、判断「画得对不对」

| 现象 | 正常应该是 | 说明 |
|---|---|---|
| 子弹飞过 | **没有框** | 只有「有骨骼的角色」才画 |
| 看自己脚下 | **没有框** | 自己 + 同队 + 2m 内三重过滤 |
| 队友 | **没有框**（除非打开「队友」） | |
| 倒地的敌人 | **没有框** | 死人字段过滤 |
| 箱子/物资 | 只有物资类单独绘制 | 不属于人形 |
| 远处 200m+ | 框很小、骨架可能不画 | 受「骨骼距离」限制 |

## 五、出问题了怎么办

### 5.1 菜单打不开 / 悬浮按钮不见了

- 双击悬浮按钮 → 会重新居中；
- 还是不行：杀进程重开小玉。

### 5.2 一个框都没有

按顺序排查：

1. 菜单里「总开关」「启用绘制」是否都打开；
2. 是否在**对局/训练营**里（大厅没有角色）；
3. 看 App 底部「构建信息」是否是最新版本；
4. 换一次地图/重新进对局（句柄可能失效）。

### 5.3 显示「KFD 初始化失败」

- 关掉小玉，**先开小玉再开游戏**；
- 如果是越狱机，确认越狱状态还在（重启后要重新越狱）；
- 检查是否同时开了别的同类工具（内核句柄独占，第二个会拿到 -4）。

### 5.4 头甲显示 `头- 甲- 包-`

说明这一局没读到装备（人机可能真的没穿，或者刚刷新）。

- 换个有装备的人机再看；
- 或者退出重进一局。

### 5.5 名字显示「敌人 / 人机」

- 人机本来就没有名字（没有 PlayerState）；
- 真人名字读不到时才会退化成「敌人」。

### 5.6 还没进对局就被踢 / 闪退

- 先确认不是在更新/校验阶段开绘制；
- 关掉「射线」「骨骼」再试，减少绘制量。

## 六、给自己的调试信息（日志）

小玉会把每帧扫描结果写到：

```
/var/mobile/Media/mf-debug/mf-live.txt
```

每行一个 Actor：

```
A[104] 0x16eb08000 pos=29905.2,27670.8,102.5 idx=65535 enc=0 team=0 ai=0 bone=75 eq=11010006002/11050006002
```

| 字段 | 含义 |
|---|---|
| `pos` | 世界坐标（cm） |
| `team` | 队伍号（自己 1、人机 0） |
| `ai` | 人机标志字节 |
| `bone` | 骨骼数量（0 = 不是角色） |
| `eq` | 装备槽原始物品 ID（`1101…`=头，`1105…`=甲） |

**取日志的方法**（电脑上执行）：

```powershell
py -3.12 -m pymobiledevice3 afc pull mf-debug/mf-live.txt .\mf-live.txt
```

## 七、常用组合推荐

| 场景 | 建议开关 |
|---|---|
| 训练营练枪 | 人机✔ 队友✘ 骨骼✔ 头甲✔ 血量✔ 射线✘ |
| 排位实战 | 人机✔ 队友✘ 骨骼✔（近距离）距离✔ 射线按喜好 |
| 只想看位置 | 骨骼✘ 名字✘ 头甲✘ 只留框 + 距离 |

## 八、版本对照（装错版本会缺功能）

| 版本 | 加了什么 |
|---|---|
| 148 | 只画有骨骼的角色；小玉排版 |
| 152 | 射线改从屏幕顶部 |
| 153 | 死人 / 观战过滤 |
| 155 | 全部判据接进真正绘制路径 |
| 156 | 名字 + 玩家 ID |
| 157 | 头甲自适应扫描 |
| **158** | **血条**（推荐装这个） |

## 九、一句话总结

> **先开小玉 → 再开游戏 → 按钮点开 → 勾「启用绘制」**。
> 没框先看版本号，头甲空看那一局有没有装备。
