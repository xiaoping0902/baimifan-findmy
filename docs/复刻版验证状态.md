## 二、【已证】的部分（有构建产物可复核）

### 2.1 包结构与伪装身份

`scripts/verify_ipa.py` 从 IPA 里直接读出来的：

| 项 | 值 | 验证方式 |
|---|---|---|
| Mach-O magic | `0xFEEDFACF` | 直接读文件头前 4 字节 |
| cputype | `0x0100000C`（ARM64） | 同上 |
| filetype | `2`（MH_EXECUTE） | 同上 |
| `CFBundleDisplayName` | **查找** | plistlib 解析 |
| `CFBundleIdentifier` | **com.apple.findmy** | 同上 |
| `CFBundleExecutable` | `FindMy` | 同上 |
| 图标 | `AppIcon60x60@2x.png` / `AppIcon76x76@2x~ipad.png` | 包内文件列表 |

**`com.apple.findmy` 的来源**：`joeblau/apple-bundle-identifiers`（Find My iOS 13+）。
这是**第三方整理的公开列表**，不是从设备上读的 —— 但白米饭用的同类手段（`com.apple.MobileStore`）已在你的设备上验证过可行。

### 2.2 entitlements 注入

**这是 M0 成败的命门，我做了逐条核对**：

把 entitlements 抠出来解析，7 项全部在位：

```
✓ platform-application
✓ com.apple.private.security.no-sandbox
✓ com.apple.private.security.storage.AppBundles
✓ com.apple.private.persona-mgmt
✓ com.apple.springboard.accessibility-window-hosting
✓ task_for_pid-allow
✓ com.apple.security.exception.iokit-user-client-class = [AGXDeviceUserClient, IOSurfaceRootUserClient]
```

**【未证】**：这 7 项在 TrollStore 环境下**是否真被内核认可**。
`ldid` 写进去了 ≠ 系统会给你这些权限。**这一步必须装机才知道。**

## 四、【做不到】的部分（缺前提，不是没做）

### 4.1 游戏对象偏移 —— 这是硬边界

| 项 | 白米饭分析里的标注 | 我们的现状 |
|---|---|---|
| 目标游戏**进程名** | 【未证】运行时解密，静态全空 | 预留字段 + **点进程即自动回填并落盘** |
| 目标游戏**模块名** | 【未证】 | 同上 |
| 物资**等级/价值字段偏移** | 【未证】取值点未逐条钉死 | `Offsets.h` 里是 `0x0` 占位 |
| **骨骼连线拓扑 + 矩阵来源** | 【未证】 | 用「头-颈-肩-胯-脚」简化骨架顶替 |
| 血量字段来源 | 【未证】 | 血条先画满格占位 |

**为什么做不到**：这些是**目标游戏**的逆向结果，不是白米饭的。白米饭的作者能写出来，是因为他先逆了游戏。

**已经铺好的路**：
- `Game/Offsets.h` —— 一张表改一处
- `MFProcessViewController` 点进程即绑定 + 进程名回写 Documents 落盘
- 「游戏数据自检」一键复制全部读数（相机 / 实体数 / 物资数 / 读取统计 / 偏移表）

**只要有游戏本体，这些是纯体力活，不是难题。**

### 4.2 投射算法的两个分量式

白米饭分析里【已证】了：
- 深度 = `dx·cosP·cosY + dy·cosP·sinY + dz·sinP`
- 深度 < 0.1 → 哨兵 `(-9999, -9999)`
- 焦距 = `tan(FOV × π/360)`

但**没逐条列出「横向分量 / 纵向分量」的确切表达式**（报告只写了这两个词）。

我按标准相机模型补全：
```
右向量 R = (-sinY,  cosY, 0)
上向量 U = (-sinP·cosY, -sinP·sinY, cosP)      （已验算与前向正交）
```

**并且做成了可翻转的**：`MFSignConvention` 三个布尔开关（横向取反 / 纵向取反 / 是否应用横滚）。
**真机上如果画面左右或上下镜像，翻一个布尔就行，不用重推数学。**

### 第 1 步 · 装机 + 自检（安全）

装 `FindMy-M4.1.ipa` → 打开控制台 → 看自检页三项路径。

| 结果 | 含义 | 下一步 |
|---|---|---|
| 三项全 ✓ | entitlements 真生效 | 进第 2 步 |
| 有 × | entitlements 没生效 | 回查 TrollStore 安装方式 |

### 第 2 步 · 悬浮窗（安全）

点「启动悬浮窗」→ 看有没有浮出 ImGui 菜单。

| 结果 | 含义 |
|---|---|
| 出菜单、汉字正常、能拖能点 | ImGui/Metal/托管/中文渲染 全通 |
| 没出 | 看设备日志 `[MF][HUD]` 开头的行 |

### 第 3 步 · 能力探测（安全，不跑漏洞）

「启动内核」页 → 底部「能力探测」→ **复制报告**。

这份报告直接回答：
- 有没有 tfp0
- **路 B 能不能枚举进程** ← 这条通了，即使 KFD 起不来，进程列表也可用

### 第 4 步 · 启动内核（⚠️ 有风险）

**只有在第 1–3 步都过了、并且你接受设备可能重启的前提下再做。**

已知风险：
- landa 失败率社区反馈不低（已加 3 次上限，不会卡死）
- 失败后内核态可能脏 → **重启 App 再试，不要原地重试**
- 严重时可能 kernel panic 导致设备重启
