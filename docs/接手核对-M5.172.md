## 3. 第 6 个致命错误（本报告没写的那条）

```
MFDrawingLayer.mm:377  acquireFrameWithSize:
   └─ :391  if (calibrated.ready && calibrated.rootObjectBase != 0)
              │        ↑ ready 能真   ↑ 恒为 0（生产代码零赋值）
              └─ :398  readFrameWithSize: → readEntitiesWithCamera:（M5.155–164 全部改在这里）
   └─ :417  acquireUE4FrameWithSize:      ← 真机每帧走的是这条
```

第二条同类：

```
MFUEReader.mm:209  enumerateActors:（全字段：剔除/头甲/UIN/武器/观察者）
                   ← 全仓库 0 处调用（grep 只命中定义 + 头文件声明）
```

**现役路径（`MFDrawingLayer.mm:520-770`）实际只产出：**

| 字段 | 来源 | 结果 |
|---|---|---|
| 相机 | `Controller+0x408` → `+0x2D60+0x10` | ✅ |
| 坐标 | `actor+0x180` → `+0x220` | ✅（轮转预算，非全量） |
| 类名 / 分类 | `UObject::Class@0x08` → `+0x1C` | ✅ |
| 人机位 | `+0xE60` | ✅ |
| 物资 | `MFGearReader`（2s 缓存） | ✅ |
| **自己 / 队友 / 观战 / 死人** | — | ❌ 不筛 |
| **头 / 甲 / 包** | — | ❌ 恒「头- 甲- 包-」 |
| **血量** | 默认 -1 | ❌ 血条恒满格 |
| **队伍 / UIN / 手持** | — | ❌ 恒「队0」「持 空手」 |

> 顺带解释一个现象：`MFGameReader.mm:239` 读了 `pos`，`:256` 又读了一遍 `posNow`，后面投影用的却是 `pos`。
> 这条死代码内部的"每帧 1 次读"实际是 2 次——**它连自己写的账都对不上**，可以当作它从没跑过的旁证。
